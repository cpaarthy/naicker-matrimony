# V7 Professional Matrimony Features

Included:
- Interest request lifecycle: send, pending, accept, decline, withdraw.
- Shortlist/Favourites with member-safe profile reads.
- Notifications for interest events and admin status events.
- Advanced search: age, education, occupation, caste/sub-caste, income, horoscope, lifestyle, verification, mother tongue, family type and height range.
- Safety: block/unblock and report profile workflow.
- Admin analytics support and indexes.

Not included by request:
- Private messaging/chat.
- Multiple-photo/profile gallery.

Run `V7_PROFESSIONAL_FEATURES_MIGRATION.sql` once in Supabase after the current V6 privacy migration.
